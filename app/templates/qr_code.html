Avant d'imprimer : scannez toujours votre QR code avec votre téléphone. Gardez un code foncé sur fond clair, et prévoyez au moins 2 cm de côté sur le support imprimé.

Pour les avis Google : il vous faut l'identifiant de votre lieu (Place ID, il commence par « ChIJ »). Vous le trouvez avec l'outil officiel de Google en tapant le nom de votre établissement. Le QR code ouvre directement la fenêtre pour laisser un avis.

Les QR codes créés ici sont statiques : rien n'est enregistré sur nos serveurs et ils fonctionneront aussi longtemps que le lien qu'ils contiennent.
